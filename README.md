# 💭 Memories — A Collection of Cherished Words

**Memories** is a simple interactive web project created to collect and preserve special messages and memories from friends.

The idea behind this project is simple: I wanted to create a small webpage that I could share with my friends, where they could leave a few words that I could **cherish forever**. ❤️

## 🌸 How It Works

The webpage asks visitors a few simple questions, such as:

* **What is your name?**
* **How do you call me?**
* **Write something for me that I can cherish forever.**

Once a friend submits their response, the information is automatically stored in a **Google Sheet** using **Google Apps Script**.

This makes it easy to collect and preserve everyone's memories in one place.

## 🛠️ Technologies Used

* **HTML** – Created the webpage and form interface
* **Google Sheets** – Stored the collected memories and responses
* **Google Apps Script** – Connected the webpage with Google Sheets and handled form submissions

## 🔄 Project Workflow

```text
Friend opens the webpage
        ↓
Enters their name
        ↓
Answers "How do you call me?"
        ↓
Writes a special message
        ↓
Submits the form
        ↓
Google Apps Script processes the response
        ↓
Response is stored in Google Sheets
```

## 🎯 Purpose

This project was created to combine **technology with personal memories**.

Instead of letting meaningful messages disappear in chats or social media, this project provides a simple way to collect them and keep them together as a personal memory collection.
